# 今天吃什麼？| 食譜靈感抽籤機

不知道今晚要吃什麼嗎？轉個輪盤、翻翻冰箱食材，讓靈感幫你決定這一餐！

資料來源：[TheMealDB](https://www.themealdb.com/)（學習用途）

## 功能介紹

### 🎡 轉盤抽籤
- 按下中央的 **GO** 按鈕，轉盤會隨機轉出今晚的菜色分類
- 8 個扇區：雞肉、牛肉、海鮮、全素、義大利麵、甜點，以及兩個隱藏的「驚喜」選項（隨機抽一道）
- 停止後自動彈出該道菜的完整食譜

### 🔍 食材搜尋
- 輸入冰箱裡有的食材（例如 `Chicken`、`Tomato`），搜尋含有該食材的食譜
- 提供 6 個熱門食材快速標籤，一鍵搜尋
- 搜尋中會顯示載入動畫，找不到時會顯示空狀態提示

### 📖 食譜詳細彈窗
- 點擊「查看食譜」或轉盤抽中的結果，顯示食譜詳細資訊
- 內容包含：菜名、分類/地區標籤、食材與份量清單、做法步驟
- 若有 YouTube 教學影片會提供連結，沒有時自動帶到 YouTube 搜尋結果
- 支援關閉按鈕、點擊背景關閉、按 `Esc` 關閉

## 如何開啟

### 方式一：直接用瀏覽器開啟（最簡單）
雙擊 `index.html` 即可使用（本專案為純靜態網頁，無需安裝任何東西）。

### 方式二：本機預覽伺服器
在本資料夾執行：

```bash
npx wrangler pages dev .
```

然後打開 `http://localhost:8788`。

### 方式三：線上版（Cloudflare Pages）
已部署的網址：

```
https://my-recipe-app.pages.dev
```

## 專案結構

```
09/
├── index.html          <-- 頁面骨架（輪盤頁、搜尋頁、彈窗）
├── css/
│   ├── style.css       <-- 主要樣式（版面、搜尋、彈窗）
│   └── wheel.css       <-- 轉盤專用樣式
└── js/
    ├── api.js          <-- TheMealDB API 串接（全域函式）
    ├── wheel.js        <-- 轉盤抽籤邏輯
    ├── search.js       <-- 食材搜尋與卡片渲染
    └── main.js         <-- 分頁切換與食譜彈窗
```

## 技術說明

- 純 HTML / CSS / JavaScript，無框架、無建置工具
- 使用 TheMealDB 的公開 API：
  - `filter.php?c=分類`：依分類取食譜
  - `filter.php?i=食材`：依食材取食譜
  - `random.php`：隨機取一道
  - `lookup.php?id`：取得單道食譜詳細資料
- 需要連線網路才能取得食譜資料
